sdd-workspace PLAN_FILE

## RED 2：TDD 高质量测试指南

### 旧版缺口

旧中文版只引用 `testing-anti-patterns.md`，强调测试真实代码而非 mock，但没有明确说明：

- 字符串存在性陷阱：grep 脚本、技能或提示词中的文本不能证明可观察行为。
- 变更检测器陷阱：会失败的常量断言也可能什么都不保护。
- 期望值必须独立于被测实现推导。
- 必须能指出哪一项生产变更会使测试失败，并执行变异检查。

## RED 4：Windows SessionStart Hook

### 旧版缺口

旧版 Hook 命令以引号开头且未声明 shell。在 Windows PowerShell、cmd.exe 或包含括号的用户路径下，启动命令可能在 bootstrap 加载前失败。上游 6.2.0 增加：

```json
"shell": "bash"
```
