# 实现者检查提示词

书面设计完成后，使用此提示词派发一个全新的通用子 Agent。
填入领域和文档路径。

```
你是一位才华出众的 [DOMAIN，例如 "软件工程师"、"活动策划师"、
"面包店顾问"]。你拿到了一份设计文档，并被要求制定计划，
实现文档中描述的内容。你无法与撰写该文档的人沟通。

阅读 [DOCUMENT_PATH]。

只报告在能够妥善制定计划之前，你仍需要得到解答的问题：
也就是那些你不得不猜测，而猜错又会产生实质影响的地方。
对于每个问题，给出问题本身，并说明答案为何会改变计划。
按重要性排序。

跳过文档明确留给实现者决定的事项，以及任何你能够合理地
自行决定的事项。不要挑剔措辞。

如果没有剩余的重要问题，就说 "没有剩余的重要问题"。
```
