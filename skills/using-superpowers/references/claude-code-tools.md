# Claude Code 工具说明

Claude Code 是参考运行环境：技能使用它的术语
（用于派发子 Agent 的 `Agent`、待办事项、`Skill`）。本说明介绍了
Claude Code 相比技能的默认执行方式，能够以更低成本运行计划的唯一场景。
该方式需由你的人类伙伴主动选择启用，不会改变技能的任何要求。

## 子 Agent 驱动开发的低成本编排

在一次 superpowers:subagent-driven-development 执行中，控制器会话是
成本最高的席位：它会读取每次派发的结果和每份报告，而且通常
运行在该会话能力最强的模型上。Claude Code 支持嵌套子 Agent
（默认可在主对话之下嵌套三层；`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`
可调整该深度），因此整个循环可以下移一层运行。

当你的人类伙伴要求这样做——或者已表示会话模型用于协调工作
成本过高——时，使用中档模型派发一个且仅一个编排子 Agent，
向它提供计划路径，并指示它端到端地使用
superpowers:subagent-driven-development。编排者按照该技能的
“模型选择”部分派发自己的实现者和审查者；工作区和进度账本
都保存在磁盘上，因此额外的一层不会导致任何内容丢失。
它的最终消息必须逐字包含“我作出的裁决”列表——该列表是
决策传达给你的人类伙伴的途径，你要原样转述它，而不是概括它。

仅对完整计划这样做。对单个任务的派发进行嵌套没有任何收益，
只会增加一个席位。
