# 查找会话历史记录

使用当前环境中可用的工具和信息，确定你的人类伙伴指定的会话。你的知识可以提示查找方向；请根据实际历史记录核实结果。

使用运行框架提供的会话工具、已配置的存储、本地帮助、文档，或在限定范围内检查文件系统。在读取文件内容之前，先测量文件大小，并遵循 context-safety.md。当环境指向归档或索引时，检查这些归档或索引。如果已提供可用路径，就无需再次搜索。

利用可用的会话 ID、工作目录、时间戳和相匹配的对话内容确认会话身份。仅凭时间较近这一点不足以确认身份。将所请求的会话与其子会话以及无关的候选会话区分开来。当现有证据无法区分它们时，请求补充缺失的识别信息。

对于每个文件系统来源，从环境中获取其完整的绝对路径，并展开其中的主目录简写和变量。在案例记录和向人类伙伴提供的查找答复中，使用同一路径。

根据观察到的记录或文档，明确所请求调查所需的记录含义。将人类消息与注入的消息、工具结果以及父 Agent 的派发消息区分开来。将工具调用与其结果对应起来。在计算总量之前，先明确用量计数器的语义。不要根据另一个运行框架推断格式，也不要将缺失的字段当作零。

在案例文件中记录确切的来源、相关字段的含义、作为依据的记录的位置、关联会话、已排除的合理候选项，以及尚未厘清的信息。后续读者应使用该记录，而不是重复进行查找。如果历史记录缺失、无法访问或存在歧义，请说明具体限制，并请求提供缺失的路径、导出数据或识别细节。
