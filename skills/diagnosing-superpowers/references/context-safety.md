# 会话转录的上下文安全

一条转录记录可能超过一兆字节，也可能嵌入完整的历史记录。打印一整条记录可能导致正在进行诊断的会话上下文溢出。
所有会话文件的读取者，无论是控制器还是子 Agent，每次读取每个文件时都要遵循这些规则。

1. **先测量，再读取。**

   ```bash
   wc -lc "$F"
   awk '{ if (length($0) > 100000) print NR, length($0) }' "$F"   # 长行
   ```

2. **绝不要用 `cat` 或 `grep` 读取内容。** 先获取行号和计数
   （`grep -n … | cut -d: -f1`、`jq -r '.type' | sort | uniq -c`），
   再从指定行中提取较小的字段（`sed -n Np | jq -c '{…}'` 或
   `| cut -c1-500`）。使用在发现阶段为当前数据源确定的字段提取命令。
3. **缩减任何超过 500 个字符的内容。** 如果命令对一条记录返回的内容超过
   500 个字符，就缩小字段或切片范围。
4. **只读。** 绝不要修改、移动或删除会话文件。
