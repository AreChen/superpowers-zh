维度：受阻点

找出会话停止推进的每一个节点。

来源，各项均使用案例文件中有证据支持的记录含义和提取
命令来定位行号：
- 被标记为错误、非零退出或明确失败记录的工具结果；
- 失败的 shell 命令（结果中退出码非零、出现 "command not
  found" 或 "No such file"）；
- 重试：发生错误后，在同一轮次内再次发起
  同一个工具调用；
- 已回退的编辑：一次编辑之后又进行一次编辑，恢复先前的
  内容，或对会话操作过的文件执行 `git checkout`/`git restore`/`git revert`/`git reset`；
- 助手文本中的回退表述（“其实”、“让我改为”、“那是
  错的”、“我看错了”）；
- 人类纠正：人类提示与助手紧接其前的操作相矛盾，或纠正
  该操作；
- 权限拒绝、钩子失败、API 错误、速率限制、轮次中止，
  以及任务中途触发的上下文溢出或压缩。

对于每个受阻点，报告行号、轮次、失败之处，以及之后发生了什么
（在同一轮次中恢复 / 稍后在第 N 行恢复 / 从未
恢复）。将相同的重复失败归为一条发现，并标明
次数。
