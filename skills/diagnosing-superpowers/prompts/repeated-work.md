维度：重复工作

找出会话中执行过不止一次的工作。

1. 将每次工具调用提取为 `(line, turn, tool, key)`，其中 `key` 为：
   读取/编辑/写入操作的文件路径；shell 调用的命令文本（去掉
   末尾的空白字符；保留完整命令）；子 Agent 派发的 `description` 加上
   提示词的前 80 个字符；搜索的查询。
2. 按 `(tool, key)` 分组，并报告达到或超过阈值的组：

   | 类别 | 阈值 | 豁免项 |
   |---|---|---|
   | 读取、搜索 | 3 | |
   | 编辑 | 2 | |
   | shell 命令 | 2 | 状态检查和测试运行（`git status`、`ls`、`pwd`、测试运行器） |
   | 子 Agent 派发 | 2，且描述相同 | |
3. 对于每个组，检查重复操作之间是否发生了任何变化（对该
   文件的写入、一次上下文压缩、一次人类纠正）。说明属于哪种
   情况；编辑后的重新读取不算一项发现，上下文压缩后的
   重新读取算一项发现，并归因于该次上下文压缩，中间什么也没发生的
   重新读取本身就是一项发现。
4. 查找重新推导的决策：助手文本得出了会话中先前已经陈述过的结论
   （同一个文件、同一个设计选择、同一条要运行的命令）。
   引用这两处内容。
5. 每组提供一项发现，附上第一处和最后一处的行号以及
   出现次数。
